# スプレッドシートへの控えの設定手順（Google Apps Script）

アプリの記録・日報・タスク・毎日の時刻・タイマーを、Google スプレッドシートに控えとして送る仕組み（D-050）。
すべて無料の範囲で行う。作業は PC のブラウザで行うと楽（iPhone でもできるが画面が狭い）。所要 10〜15 分。

- 送るのはアプリ → スプレッドシートの一方向だけ。スプレッドシートを書き換えてもアプリには戻らない（端末が正本）
- 合言葉は、メモアプリ等にだけ控える。チャット・リポジトリ・スクリーンショットには載せない

## 0. 合言葉（SYNC_TOKEN）を作る

20 文字以上のランダムな文字列（iPhone の「パスワード」アプリやパスワード生成ツールで作る）。送信サーバーの合言葉（APP_TOKEN）とは別にする。

## 1. スプレッドシートを作る

1. Google ドライブで「新規」→「Google スプレッドシート」。名前は `キィニチ 控え` など
2. シートの中身は空のままでよい（初めて送ったときに「記録」「日報」「タスク」「毎日の時刻」「タイマー」「同期」のシートが自動でできる）

## 2. コードを貼り付ける

1. そのスプレッドシートで「拡張機能」→「Apps Script」
2. 左の `コード.gs`（または `Code.gs`）の中身を全部消し、このリポジトリの `gas/Code.gs` の中身を丸ごと貼り付ける（https://github.com/kana13914-pixel/kiinichi-manager/blob/main/gas/Code.gs の「Raw」表示をコピー）
3. 上の保存ボタン（フロッピーの絵）を押す

## 3. 合言葉を登録する

1. Apps Script の左の歯車「プロジェクトの設定」→ 下の方の「スクリプト プロパティ」→「スクリプト プロパティを追加」
2. **プロパティを `SYNC_TOKEN`**（大文字）、値に手順 0 の合言葉を入れて「スクリプト プロパティを保存」

## 4. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」→ 左の歯車で「ウェブアプリ」を選ぶ
2. 「次のユーザーとして実行」＝**自分**、「アクセスできるユーザー」＝**全員**
   - 「全員」にするのは、アプリ（ログインしていない）から送れるようにするため。中身は合言葉で守る。URL を知っていても合言葉がなければ何も書けない
3. 「デプロイ」→ アクセスの承認を求められたら、自分のアカウントを選んで「許可」（「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」。自分で作ったスクリプトなので問題ない）
4. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピーする。この URL も人に見せない

## 5. アプリに入れる

1. ホーム画面のアプリ → 右上の設定 →「スプレッドシートへの控え」
2. 「送り先の URL」に手順 4 の URL、「合言葉」に手順 0 の合言葉を貼り付ける
3. 「今すぐ送る」→「◯◯ に送りました」と出ればよい
4. スプレッドシートを開き直すと、シートが増えて中身が入っている

以後は、アプリで記録などを変えると自動で送る（5 秒待ってまとめて、1 分に 1 回まで）。通信できなかったときは、次に変えたとき・開いたときにやり直す。

## コードを更新するとき（`gas/Code.gs` が変わったら）

1. Apps Script を開き、`Code.gs` の中身を新しいものに貼り替えて保存
2. 「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→「バージョン」を「新しいバージョン」→「デプロイ」
   - 「新しいデプロイ」ではなく「デプロイを管理」から行う（URL が変わらない）

## うまくいかないとき

| アプリに出る文 | 見るところ |
| --- | --- |
| 合言葉が違います | 手順 3 の値とアプリの合言葉が同じか（前後の空白に注意） |
| スクリプト プロパティ SYNC_TOKEN が未設定です | 手順 3 |
| 通信できません | URL が `/exec` で終わっているか。手順 4 の「アクセスできるユーザー」が「全員」か |
