# 見た目の決まり（CR-*）

アプリ全体の色・形・線・文字・地・装飾・動きの決まり。画面を作る・直すときは、この ID を引用する。
決定は D-021（v7「懸木の狩人」）、実装時の補足は D-022。トークンの値は `app/style.css` の `:root`、表は `docs/design.md`。
出典：`docs/research/2026-11-08_round3_visual/visual_rules_v7_instructions_for_ai.md`（R3-Q3）§3。キャラクターの事実は同フォルダの R3-Q1。

> コンセプト：「静かな面に、金の細線。角は斜めに切り、差し色は小さく。」

## 色 CR-C

| ID | 決まり |
| --- | --- |
| CR-C01 | 面は 3 段＋最奥：地（深緑のグラデーション）→ セリフ面・カード（黒 90%/55%）→ 最奥（`--color-ink` タブバー・控えめボタンの地） |
| CR-C02 | 金（`--color-accent`）の**塗り**は画面に 1 つ（主ボタン）。金の**文字**は名前と選択中タブだけ（V3-08）。金の**線**（`--color-gold-line` 55%、`--color-gold-faint` 18%）は装飾として使ってよい |
| CR-C03 | 差し色（ライム・青・橙・白）は装飾専用で、画面面積の 2% 以内。文字色には使わない。例外：`--color-success`（ライム）で書く「記録済み」と「成功・完了の状態表示」（設定の「登録済み」など。D-021） |
| CR-C04 | 多色（差し色 4 つを並べる）は 1 画面 1 か所。ホームでは「次の予定」の数珠 |
| CR-C05 | 夜（22〜4 時）は面を一段暗くし、上からの光を消して足元に淡い火（`--color-ember-glow`）を置く |

## 形 CR-S

| ID | 決まり |
| --- | --- |
| CR-S01 | 面とボタンは**左上と右下の 2 角を 45° に落とす**（`clip-path`）。`--cut-s` 6px（小ボタン・トースト）／`--cut-m` 10px（記録ボタン・カード）／`--cut-l` 14px（セリフ面） |
| CR-S02 | 縁のある部品は「外側を縁の色で塗る＋`::before` を 1px 内側に塗りの色で重ねる」で斜めの縁を描く（`border` は `clip-path` で欠けるため使わない）。トーストも同じ（D-022） |
| CR-S03 | 角丸とピル形は新しく作らない。入力欄（`input`）だけは角丸 8px を残す |
| CR-S04 | 鋭角（45° より鋭いトゲ）は使わない |
| CR-S05 | `clip-path` は外側の影・枠（`box-shadow`・`outline`）を切り落とす。斜めの部品で強調・選択中を示すときは、縁の色（`--btn-line`）を変えるか、拡大縮小（`transform`）で示す（D-022） |

## 線・模様 CR-L

| ID | 決まり |
| --- | --- |
| CR-L01 | 区切りは 1px の金の細線（`--color-gold-line` / `--color-gold-faint`）。区切りに破線は使わない |
| CR-L02 | 段々の帯（`img/fret.svg`）はタブバーの上辺の 1 か所だけ |
| CR-L03 | 「次の予定」は箱にせず、上下の細線＋左の数珠で区切る |
| CR-L04 | 名前は札にしない。「ライムの菱形＋名前＋右へ消える金の線」 |

## 文字 CR-T

| ID | 決まり |
| --- | --- |
| CR-T01 | ジャンプ率を上げるのは時刻だけ：`--fs-display` 48px・ウェイト 300・字間 -0.02em・等幅数字。日付は時刻の上に 13px |
| CR-T02 | 英字の小見出し（`.label-en`）は 11px・太字・字間 0.18em・`--color-text-tertiary`・`aria-hidden`。**各画面に 1 つだけ**（ホーム `NEXT`、ほかは h1 の上に `SCHEDULE`／`TASKS`／`TIMER`／`REPORT`／`SETTINGS`） |
| CR-T03 | 名前は字間 0.14em。本文・セリフは 17px / 行間 1.7 |
| CR-T04 | Web フォントは使わない（システムフォント。公式フォントは禁止） |

## 地・質感 CR-B

| ID | 決まり |
| --- | --- |
| CR-B01 | 地は上（`--color-bg-top`）から下（`--color-bg-bottom`）へ暗くなる縦グラデーション |
| CR-B02 | 昼は上から淡いライムの光（`--bg-glow`、12%） |
| CR-B03 | 全面に白 4.5% の粒（`img/grain.svg`）。ガラス風のぼかしはセリフ面だけ（D-021 で維持を確認） |

## 立ち絵なしの「気配」CR-P

| ID | 決まり |
| --- | --- |
| CR-P01 | 破線の「立ち絵（仮）」は出さない。`#portrait` は立ち絵の枠として残し、立ち絵がない間は紋章（`img/canopy-emblem.svg`）を出す |
| CR-P02 | 紋章は自作の幾何学（太陽の輪＋16 本の光＋四弁＋菱形＋ロープの弧とフックの巻き）。公式の元素マーク・紋章に似せない |
| CR-P03 | 舞台の上部から 3 本の吊り線（`img/canopy-vines.svg`）、右端に縁取りだけの縦書き `KINICH`（高さは舞台の 17% まで） |
| CR-P04 | 立ち絵は `app/img/portrait.webp`（または `.png`）を置くだけで自動で表示され、紋章が消える（D-022）。手順は `docs/roadmap.md` の「立ち絵の差し替え」 |

## 動き CR-M

| ID | 決まり |
| --- | --- |
| CR-M01 | セリフが替わるたび、左から 12px 引き寄せるように 260ms で入る（`.line-enter`） |
| CR-M02 | 新しい動きは 300ms 以内・1 回きり。繰り返す動きは通知時の脈動 2 回だけ（拡大縮小で示す。D-022） |
| CR-M03 | 動きを減らす設定ではすべて止める |

## アクセシビリティの守り CR-A（変えてはいけない）

| ID | 決まり |
| --- | --- |
| CR-A01 | 文字 4.5:1、部品の境界 3:1（`scripts/contrast_check.py`） |
| CR-A02 | タップ領域 44px 以上、記録ボタン 52px |
| CR-A03 | 装飾（紋章・吊り線・縦書き・NEXT・菱形・数珠・帯）は読み上げない |
| CR-A04 | iPhone SE（375×667）で 1 画面に収まる |

## 禁止 CR-X

- CR-X01 キィニチ・アハウ本人の描画、公式素材・公式 UI・公式フォント・ボイスの利用
- CR-X02 装飾を全部品に足す（1 画面 1〜2 か所）。増やすときは利用者に確認
- CR-X03 差し色を広い面・文字に使う（CR-C03 の例外を除く）
- CR-X04 ガラス風を全面に使う
- CR-X05 `--color-*` に `var()` を入れる（コントラスト計算が壊れる）
