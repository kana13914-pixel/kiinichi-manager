# Q1 取り入れるべき知識領域マップ — キィニチくん専属マネージャー

本アプリに必要な知識は 5 分野・23 領域。一般的な UI の基礎（第1・2部）に加え、「iPhone の PWA」「キャラクターが生活に声を掛ける」という 2 つの特徴から、第3・4部が本アプリ固有の必須知識になる。

優先度：**A** = ホーム画面の今回の修正にすぐ効く／**B** = 次の画面（予定・タスク・日報）やフェーズ2〜4で効く／**C** = 余裕があれば
