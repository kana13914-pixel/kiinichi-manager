# R6：全画面の見た目のレビュー（2026-11-18、phase3-v7 → phase3-v8）

phase3-v7（`6f718ea`）の全画面を、朝 7:40・昼 12:30・夕方 18:10・夜 23:30、空・入力中・確認・スクロール中の状態で、iPhone 15（393×852、上 59・下 34）と SE（375×667、上 20・下 0）で撮影し、`docs/visual_rules.md`（CR-*）・`docs/ui_knowledge.md`・決定（D-*）と照らし合わせた。決定は D-064。

撮影はヘッドレス Chrome（Playwright）で、時計を固定し、タスク 6 件・日報 6 日分・カレンダーの予定 6 件・先週のひとことを入れた状態で行った。iOS 固有の見え方（ステータスバーの文字、日付・時刻の入力欄の表示）は実機で確かめる（M1-04）。

## 見たが直していないもの（理由）

| 内容 | 理由 |
| --- | --- |
| ホームの配置・時計・紋章 | 利用者が気に入っている。決まりにも沿っていた |
| 各画面の一言の面が「浮いていて無機質より」（`docs/feedback/README.md` 2026-11-16） | 利用者の希望で「装飾を足すときに考える」。今回は装飾を足していない |
| 予定のリストの行を詰める | R5 Q-R5-6 で利用者が「詰めない」と決めた。今回は太さと色だけで見分けやすくした |
| 先週のひとことと画面上の一言が、週明けの次の日から同じ画面に 2 つ出る | CR-G05（D-060 ⑤）の決めたとおり。2 つは画面の上と下に離れている |
| タイマーが終わった画面の下半分が空く | 低。終わった画面はすぐ閉じるので、今は直さない |
| 通知の本文の言い回し（R5 P12） | セリフの文面の変更は利用者の確認が要る。今回は見た目だけを扱った |
| 日付・時刻の入力欄の英語表記（mm/dd/yyyy、PM） | 撮影環境の言語のため。iPhone では日本語で出る |
