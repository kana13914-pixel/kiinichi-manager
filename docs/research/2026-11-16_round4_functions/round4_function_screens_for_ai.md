## 1. 診断（R3-Q2 の F4 の 10 観点。v16 を iPhone 15 / SE で撮影）

2＝問題大。ホームはすでに 0〜1 なので、差の大きい所が「ホームは大丈夫、ほかはダサい」の正体。

| No | 観点 | ホーム | 機能画面 | 根拠（v16 の事実） |
| --- | --- | --- | --- | --- |
| D1 | 形 | 0 | 1 | ボタンは斜め角でそろっているが、入力欄・日付欄は角丸、月のタグは四角い黒箱で、形の文法が混ざる |
| D2 | 線 | 0 | 1 | 見出しの下に区切りがなく、見出しと中身がつながっていない |
| D3 | 面の階層 | 0 | **2** | 入力欄・チップ・控えめボタン・月のタグがすべて最奥の黒（`--color-ink` / `--color-bg-deep`）。地の緑に黒い穴が並ぶ。日報は穴が 3 つ縦に並ぶ |
| D4 | 色の構成 | 0 | 1 | 差し色が機能画面で一度も使われない（記録済みのライムのみ） |
| D5 | 文字の階層 | 0 | 1 | タスクの期限の違い（期限切れ・今日・期限なし）が行の補足の文字だけ。並びの意味が見えない |
| D6 | 質感・奥行き | 0 | 0 | 地の粒と光は全画面に効いている |
| D7 | 余白の意味 | 0 | **2** | タイマー動作中・タイマー一覧・タスク 0 件で、画面の下半分が何もない |
| D8 | 固有モチーフ | 0 | **2** | 紋章・吊り線などの「らしさ」はホームだけ。機能画面のらしさは一言の面だけ |
| D9 | 動き | 0 | 1 | タイマーは数字が変わるだけで「進んでいる」感覚がない |
| D10 | 実際の不具合 | 0 | **2** | 予定（SE・月表示）で、貼り付く日付の見出しがタブバーの上に重なり、タブが隠れる（`z-index` の順序） |

結論：
- 「もっさり」＝ D3（黒い穴の重さ）＋ D7（空白の放置）＋ D9（進みが見えない）。
- 「ダサい」＝ D1・D2（形と線の文法がホームほど徹底されていない）＋ D10（重なりの崩れ）。
- 足りない知識はホーム中心の資料に無かった「フォーム・リスト・空の状態・予定表示・進み具合・機能の中のらしさ」（知識領域マップ改訂2 の I5〜I9、C10）。

## 2. 方針

> **ホームの文法を、機能画面の部品にまで通す。新しい飾りは増やさない。**

1. **重さを抜く**：最奥の黒は「いちばん奥のもの（タブバー・セリフの面）」だけにする。入力欄・チップ・タグは一段明るい面に（CR-F01, F02, F04）。
2. **区切りで見せる**：見出しの線（CR-F05）、期限の小見出し（CR-G01）、1 本の切り替え（CR-F03）。箱を増やさず、線と見出しでまとまりを作る。
3. **らしさは「形」で先に入れる**：紋章の太陽の輪をタイマーの残り時間に（CR-G02）、差し色を日報の 7 日に（CR-G03）。セリフを増やす前にできる、利用者確認が要らない層（C10-01 ①）。
4. **不具合を先に直す**：重なり順（CR-F06）。

装飾の数（CR-X02「1 画面 1〜2 か所」）は守る。タイマーの輪と日報の 7 日は「情報の図」で、飾りではない（数字・記録を表す）。

## 7. 調査の要点（出典は `docs/ui_knowledge.md` §8 にも追記）

- 入力欄の中の説明文は打ち始めると消え、記憶の負担・見直しの難しさ・障害のある人の負担を増やす（NN/g「Placeholders in Form Fields Are Harmful」）→ I5-01。
- Google の調査で、入力欄は囲み型と塗り型が大きく上回った（Material Components「Text Fields」）→ I5-02、CR-F01。
- 空の状態は、状態を伝え、使い方を覚えさせ、主な作業への近道を示す機会（NN/g「Designing Empty States in Complex Applications」）→ I7。
- 確認の画面を何にでも出すと読まずに押す癖がつく。取り消せる操作は取り消すで守る（Matuschak ほか）→ I6-01（D-031 の形を維持）。
- 横スワイプは削除の手段として最もよく知られるが、大事な操作をスワイプに隠すと見つけられない（NN/g「Contextual Swipe」）→ I6-04、Q-C。
- セグメントは同じ内容の見せ方の切り替えに使い、追加・削除などの操作には使わない（Apple HIG）→ I8-01、CR-F03。
- 携帯の月表示は、マスを小さな印にし、選んだ日の予定を下に一覧で出す形が一般的 → I8-03（D-032 のタグ 2 つは維持）。
- 人は終わり際の遅れを特に嫌い、一定の速さか後半が速い進み方を速く感じる（Harrison ら 2007、2022 の追試）→ I9-01（実時間なので一定の速さ）。
- ジューシーな反応は体験をよくするが、盛りすぎると有能感を妨げうる（Hicks ら 2019 ほか）→ C10-04、Q-B。
- 1 日 1 色の印を並べる「Year in Pixels」は、気分の流れを一目で見せる自己記録の定番（Daylio ほか）→ CR-G03。
